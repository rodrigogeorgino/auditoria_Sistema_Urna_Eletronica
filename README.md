## 🚀 Como Executar o Projeto

### Pré-requisitos
Não é necessário instalar ex: NodeJS, Docker, Python.

### Passo a passo
1. Clone o repositório:
   ```bash
   git clone https://github.com/rodrigogeorgino/auditoria_Sistema_Urna_Eletronica
   ```
2. Entre na pasta do projeto:
   ```bash
   cd auditoria_Sistema_Urna_Eletronica
   ```
3. Execute a aplicação:
   ```bash
   Abra seu navegador. Sem instalar nada!
   ```
